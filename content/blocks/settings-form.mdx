### Composition

The block groups identity, regional defaults, numeric policy, and a boolean feature setting into one responsive form. At narrow widths every field and action becomes a single column.

### Integration boundary

Pass a standard form `onSubmit` handler or action. The block owns presentation and native form values only; persistence, validation policy, and request state remain application concerns.
